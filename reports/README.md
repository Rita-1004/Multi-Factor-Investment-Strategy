# Research Outputs

This directory contains publication-ready figures and aggregated result tables produced by the multi-factor equity research pipeline.

## Figures

The `figures/` directory contains factor, portfolio, machine-learning, and risk-analysis visualizations.

## Tables

The `tables/` directory contains final aggregated performance and statistical-inference results.

## Data Restrictions

These files contain only aggregated research outputs. Security-level CRSP, Compustat, and CCM observations are not distributed in this repository.

Monthly CRSP benchmark returns and individual security-level records are intentionally excluded because they are subject to data-provider licensing restrictions.

## Interpretation

The Quality Top 20% Equal-Weight strategy is the pre-specified primary strategy.

The Quality Top 10% Inverse-Volatility strategy is reported only as an ex-post sensitivity winner and should not be interpreted as independently validated model selection.
